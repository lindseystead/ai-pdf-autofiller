# Fill a W-9-shaped AcroForm from JSON

This recipe targets **taxpayer-ID style fields** (name, EIN, address). CI proves
the path on the synthetic `samples/w9_shaped_sample.pdf` + `w9.json` alias pack.
It is **not** a certified fill of the official IRS W-9 PDF — bring your own
publisher's AcroForm and run `/inspect` first.

## Field inventory (`samples/w9_shaped_sample.pdf`)

From `inspect()` / `POST /inspect` (regenerate anytime):

| Field | Type | Required | Maps from (examples) |
|-------|------|----------|----------------------|
| `txtNameLine1` | text | yes | `name_line_1`, `name_as_shown` |
| `txtBusinessName` | text | no | `business_name_line_2`, `dba` |
| `txtEIN` | text | yes | `ein`, `fein` |
| `txtAddr1` | text | yes | `addr1`, `address` |
| `txtCity` | text | yes | `town`, `city` |
| `txtState` | text | yes | `province`, `state` |
| `txtZIP` | text | yes | `zip`, `zipcode` |

## User data template

```json
{
  "name_line_1": "Jane Q. Doe",
  "business_name_line_2": "Doe Consulting LLC",
  "ein": "12-3456789",
  "addr1": "123 Main St",
  "town": "Springfield",
  "province": "IL",
  "zip": "62701"
}
```

## Local library (no server)

```bash
PYTHONPATH=src python3 - <<'PY'
from pdf_autofiller import inspect, preview, fill

pdf = "samples/w9_shaped_sample.pdf"
profile = {
    "name_line_1": "Jane Q. Doe",
    "business_name_line_2": "Doe Consulting LLC",
    "ein": "12-3456789",
    "addr1": "123 Main St",
    "town": "Springfield",
    "province": "IL",
    "zip": "62701",
}
print(inspect(pdf).field_count)
print([d.field_name for d in preview(pdf, profile).mapping.decisions if d.selected_value])
fill(pdf, profile, "w9_shaped_filled.pdf")
PY
```

## curl

Start the API without a token for local demos (`API_AUTH_ENABLED=false make run-api`), then:

```bash
curl -s -X POST http://localhost:8000/inspect \
  -F "pdf_file=@samples/w9_shaped_sample.pdf;type=application/pdf" | jq .

curl -s -X POST http://localhost:8000/preview \
  -F "pdf_file=@samples/w9_shaped_sample.pdf;type=application/pdf" \
  -F 'user_data={"name_line_1":"Jane Q. Doe","ein":"12-3456789","addr1":"123 Main St","town":"Springfield","province":"IL","zip":"62701"}'

curl -s -X POST http://localhost:8000/fill \
  -F "pdf_file=@samples/w9_shaped_sample.pdf;type=application/pdf" \
  -F 'user_data={"name_line_1":"Jane Q. Doe","business_name_line_2":"Doe Consulting LLC","ein":"12-3456789","addr1":"123 Main St","town":"Springfield","province":"IL","zip":"62701"}' \
  -o w9_shaped_filled.pdf
```

## Your real W-9 PDF

1. `POST /inspect` (or `inspect(path)`) and note exact field names  
2. Align JSON keys to the alias pack / field names  
3. `POST /preview` until `missing_required` is empty  
4. `POST /fill`  
5. Optionally add a redacted fixture under `tests/fixtures/corpus/` once you have redistribution rights
