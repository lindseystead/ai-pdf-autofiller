# Fill IRS Form W-9 from JSON

The W-9 collects taxpayer identification for US contractors and vendors. Field names vary by PDF publisher, but the semantic concepts are stable.

## User data template

```json
{
  "name_line_1": "Jane Q. Doe",
  "business_name_line_2": "Doe Consulting LLC",
  "tax_classification": "individual",
  "addr1": "123 Main St",
  "town": "Springfield",
  "province": "IL",
  "zipcode": "62701",
  "ssn": "123-45-6789"
}
```

For businesses using an EIN instead of SSN:

```json
{
  "name_line_1": "Doe Consulting LLC",
  "ein": "12-3456789",
  "tax_classification": "llc",
  "addr1": "456 Commerce Blvd",
  "town": "Chicago",
  "province": "IL",
  "zipcode": "60601"
}
```

## curl

```bash
curl -s -X POST http://localhost:8000/fill \
  -H "X-API-Key: ${API_AUTH_TOKEN:-}" \
  -F "pdf_file=@w9.pdf;type=application/pdf" \
  -F 'user_data={
    "name_line_1": "Jane Q. Doe",
    "business_name_line_2": "Doe Consulting LLC",
    "tax_classification": "individual",
    "addr1": "123 Main St",
    "town": "Springfield",
    "province": "IL",
    "zipcode": "62701",
    "ssn": "123-45-6789"
  }' \
  -F "strict=true" \
  -o w9-filled.pdf
```

## Python SDK

```python
from pdf_autofiller import fill

fill(
    "w9.pdf",
    {
        "name_line_1": "Jane Q. Doe",
        "addr1": "123 Main St",
        "town": "Springfield",
        "province": "IL",
        "zipcode": "62701",
        "ssn": "123-45-6789",
    },
    "w9-filled.pdf",
    api_key="your-token",
)
```

## Playground

1. Open `http://localhost:8000/playground`
2. Upload your W-9 PDF
3. Paste the JSON template above
4. Click **Fill PDF** → **Download**

## When deterministic mapping isn't enough

If your W-9 uses opaque field names, retry with:

```bash
-F "use_semantic_inference=true" \
-F "allow_fallback_mapping=true" \
-F "strict=false"
```

Requires `MODEL_PROVIDER_API_KEY` on the server.
