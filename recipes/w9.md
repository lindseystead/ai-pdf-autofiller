# Fill a W-9-shaped AcroForm from JSON

This recipe targets **taxpayer-ID style fields** (name, EIN, address). CI proves
the path on the synthetic `samples/w9_shaped_sample.pdf` + `w9.json` alias pack.
It is **not** a certified fill of the official IRS W-9 PDF — bring your own
publisher's AcroForm and run `/inspect` first.

## User data template

```json
{
  "name_line_1": "Jane Q. Doe",
  "business_name_line_2": "Doe Consulting LLC",
  "tax_classification": "individual",
  "addr1": "123 Main St",
  "town": "Springfield",
  "province": "IL",
  "zipcode": "62701",
  "ssn": "123-45-6789"
}
```

For businesses using an EIN instead of SSN:

```json
{
  "name_line_1": "Doe Consulting LLC",
  "ein": "12-3456789",
  "tax_classification": "llc",
  "addr1": "456 Commerce Blvd",
  "town": "Chicago",
  "province": "IL",
  "zipcode": "60601"
}
```

## curl

Start the API without a token for local demos (`API_AUTH_ENABLED=false make run-api`), then:

```bash
curl -s -X POST http://localhost:8000/fill \
  -F "pdf_file=@w9.pdf;type=application/pdf" \
  -F 'user_data={
    "name_line_1": "Jane Q. Doe",
    "business_name_line_2": "Doe Consulting LLC",
    "tax_classification": "individual",
    "addr1": "123 Main St",
    "town": "Springfield",
    "province": "IL",
    "zipcode": "62701",
    "ssn": "123-45-6789"
  }' \
  -F "strict=true" \
  -o w9-filled.pdf
```

When auth is enabled, add `-H "X-API-Key: ${API_AUTH_TOKEN}"`.

## Python SDK

```python
from pdf_autofiller import fill

fill(
    "w9.pdf",
    {
        "name_line_1": "Jane Q. Doe",
        "addr1": "123 Main St",
        "town": "Springfield",
        "province": "IL",
        "zipcode": "62701",
        "ssn": "123-45-6789",
    },
    "w9-filled.pdf"
)
```

## Playground

1. Open `http://localhost:8000/playground`
2. Upload your W-9 PDF
3. Paste the JSON template above
4. Click **Fill PDF** → **Download**

## When deterministic mapping isn't enough

If your W-9 uses opaque field names, retry with:

```bash
-F "use_semantic_inference=true" \
-F "allow_fallback_mapping=true" \
-F "strict=false"
```

Requires `MODEL_PROVIDER_API_KEY` on the server.
