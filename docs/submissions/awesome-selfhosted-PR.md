# awesome-selfhosted submission

Submit PDF Autofiller to the [awesome-selfhosted-data](https://github.com/awesome-selfhosted/awesome-selfhosted-data) list for long-tail discovery.

## Eligibility note

awesome-selfhosted requires projects to be **at least 4 months old** with **documented installation**. If the repo is newer, wait until eligible or open an issue using the template below instead of a PR.

## Option A: Pull request (when eligible)

1. Fork https://github.com/awesome-selfhosted/awesome-selfhosted-data
2. Create `software/pdf-autofiller.yml` with the contents of [pdf-autofiller.yml](pdf-autofiller.yml)
3. Update `demo_url` once Render playground is live
4. Open PR titled: `Add PDF Autofiller`

### PR description template

```markdown
## Add PDF Autofiller

- [x] I have read the contributing guidelines
- [x] I have checked that the software is actively maintained
- [x] Installation/docs: README + Docker + render.yaml

PDF form filling API – maps JSON user profiles to AcroForm fields without per-PDF hand mapping. Includes browser playground and Python SDK.
```

## Option B: Issue (if under 4 months)

Open a new issue → **Addition** template → paste YAML from `pdf-autofiller.yml`.

## After merge

- Traffic compounds over months from awesome-selfhosted.net SEO
- Add "Listed on awesome-selfhosted" badge to README optional section
