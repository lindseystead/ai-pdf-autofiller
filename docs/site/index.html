PDF Autofiller

Fill any AcroForm PDF from JSON — no manual field mapping. Deterministic-first, optional AI, MIT licensed.

Docker (one command)

docker run -p 8000:8000 \
  -e API_AUTH_ENABLED=false \
  ghcr.io/lindseystead/ai-pdf-autofiller:latest

Install from Release

curl -fsSL https://raw.githubusercontent.com/lindseystead/ai-pdf-autofiller/main/scripts/install-from-release.sh | bash

Python SDK

from pdf_autofiller import fill
fill("form.pdf", {
  "firstname": "Jane",
  "lastname": "Doe",
  "dob": "1990-01-01"
}, "filled.pdf")

W-9 recipe

curl -X POST localhost:8000/fill \
  -F pdf_file=@w9.pdf \
  -F 'user_data={"name_line_1":"Jane"}' \
  -o filled.pdf
